## 1.1.0

- Support PHP 8.4 and 8.5 and Nextcloud 33, 34 and 35 (#6)
- Require PHP 8.1 and Nextcloud 30 or newer
- Fix iPhone keyboard features in the editor: double space to period, autocorrect and automatic capitalization
- Move the interface to Vue 3 and the current Nextcloud components
- Replace the Markdown editor with EasyMDE and sanitize the Markdown preview
- Update the PDF and Markdown export libraries and close known security issues in them
- Keep memory use low when exporting many entries to PDF
- Show images in PDF exports as their alternative text
